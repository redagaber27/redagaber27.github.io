## ✨ المميزات الرئيسية للموقع:
1. **ثنائي اللغة بالكامل (Bilingual Arabic / English)**:
   - دعم كامل للغة العربية (RTL) والإنجليزية (LTR) بضغطة زر مع حفظ الاختيار تلقائياً.
   - خطوط احترافية (Cairo للعربية و Plus Jakarta Sans للإنجليزية).

2. **الوضع الليلي والنهاري (Dark & Light Mode)**:
   - تصميم افتراضي داكن وفخم (Dark Cyber/Fintech Theme) مع إمكانية التبديل للوضع الفاتح.

3. **حاسبة تفاعلية للعائد على الإعلانات (Interactive ROAS Calculator)**:
   - ميزة فريدة تمكّن العملاء وأصحاب المتاجر من تحريك مؤشرات الإنفاق والـ ROAS لمعرفة المبيعات المتوقعة والأرباح الإضافية مما يرفع معدل إغلاق الصفقات.

4. **نموذج تواصل مباشر يربط بالواتساب (Direct WhatsApp Lead Form)**:
   - نموذج لطلب استشارة أو إدارة حملات يقوم بتجهيز رسالة واتساب منسقة تلقائياً وإرسالها مباشرة لرقم رضا: `01002070567`.
   - مع خيار بديل للإرسال عبر البريد الإلكتروني.

5. **عرض سابقة الأعمال والمشاريع الواقعية**:
   - متجر **Homera.me** على Easy Order (رابط مباشر، تفاصيل الـ CAPI، وإعدادات Cloudflare).
   - قناة **Reda Gaber للتقنية** على YouTube (+560 فيديو منشور).
   - بروفايل **Top Media Buyer** المعتمد.
   - إدارة العلامات التجارية المتعددة (B-Link, Billiardo Corner, Homera).

6. **مصفوفة المهارات والتقنيات (Tech Stack)**:
   - ميديا باينج: Meta Ads Manager, ROAS Optimization, A/B Testing, Lookalikes.
   - متاجر وتتبع: Easy Order, Meta Pixel, Conversion API, Google Search Console, Google Merchant Center, Microsoft Clarity.
   - أدوات إبداعية: ChatGPT AI Marketing, Canva, Photoshop, CapCut.

## 🌐 كيف تفتح الموقع وتستعرضه الآن؟
1. توجه للمجلد:
   `C:\Users\RG\.gemini\antigravity\scratch\reda-gaber-portfolio`
2. اضغط مرتين على ملف `index.html` وسيفتح مباشرة في متصفحك (Chrome أو Edge أو Firefox).

أو لتشغيله عبر سيرفر محلي:
```bash
# باستخدام Python:
python -m http.server 3000

# أو باستخدام Node / npx:
npx serve .
```
ثم افتح المتصفح على: `http://localhost:3000`

## 🚀 كيفية رفع الموقع على الإنترنت مجاناً في دقيقتين:

### الخيار 1: Vercel أو Netlify (الأسهل والأسرع)
1. ادخل على [Netlify Drop](https://app.netlify.com/drop).
2. اسحب مجلد `reda-gaber-portfolio` وأفلته في الصفحة.
3. مبروك! ستحصل فوراً على رابط مباشر مجاني يعمل مدى الحياة (ويمكنك ربط دومين خاص مثل `redagaber.com` بسهولة).

### الخيار 2: GitHub Pages
1. ارفع الملفات إلى مستودع جديد على GitHub باسم `portfolio`.
2. من إعدادات المستودع (Settings) -> Pages -> اختر فرع `main` واضغط Save.
3. سيصبح موقعك متاحاً على الرابط المجاني: `https://your-username.github.io/portfolio/`.
